# Message-Market Fit Tests

## Test 1: Homepage Hero Variants
- Goal: Improve conversion to demo request.
- Variants: Control-led, Velocity-led, Reliability-led.
- Constant: Same CTA and same audience targeting.
- Primary metric: Demo request conversion rate.

## Test 2: Role Page Resonance
- Goal: Improve qualified meeting rate per persona.
- Pages: CTO, Engineering Manager, Senior Engineer.
- Primary metric: Qualified meeting rate by page.

## Test 3: Closed-Source Objection Copy
- Goal: Reduce trust-related drop-off.
- Variants: Risk-reduction framing vs accountability framing.
- Primary metric: Trust page to demo CTA conversion.

## Decision Rule
Keep only variants that beat baseline by statistically meaningful margin and maintain lead quality.
