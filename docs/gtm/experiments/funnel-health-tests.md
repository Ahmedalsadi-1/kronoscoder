# Funnel Health Tests

## Funnel Stages
1. Content view
2. Demo request
3. Pilot start
4. Paid conversion

## Monthly Targets
- Pilot-to-paid conversion must improve month-over-month.
- Trial/entry-to-team upgrade must improve month-over-month.

## Required Instrumentation
- Source attribution for top-of-funnel assets
- Stage transition timestamps
- Segment labels (startup, smb-adjacent, enterprise)

## Review Cadence
- Weekly: stage volume and conversion anomalies
- Monthly: conversion trends, churn reasons, and loss themes

## Action Rule
If two consecutive months miss target, revise messaging and pilot qualification criteria.
