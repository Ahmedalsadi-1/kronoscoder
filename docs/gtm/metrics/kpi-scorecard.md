# GTM KPI Scorecard

## North-Star Metrics
- Pilot-to-paid conversion rate
- Time from first meeting to pilot start
- Team plan expansion rate

## Supporting Metrics
- Homepage conversion to demo
- Role page qualified meeting rate
- Trust page CTA conversion
- Onboarding completion in first 7 days

## Segment Cuts
- Startup engineering teams (primary)
- SMB technical teams (secondary)
- Enterprise opportunities (later-stage)

## Monthly Review Template
1. What improved?
2. What regressed?
3. Which segment moved the most?
4. Which message variant won?
5. What changes next month?
