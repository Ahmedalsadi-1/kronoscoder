# KronosChamber + KronosCode GTM Kit (Closed-Source)

This folder operationalizes the high-level GTM plan into reusable assets for marketing, product marketing, founder-led sales, and pilot execution.

## Strategy Defaults
- Positioning: premium, closed-source software delivery platform
- Primary ICP: startup engineering teams (10-150 engineers)
- Motion: product-led demand + founder-led conversion
- Commercial model: tiered SaaS + team seats

## Asset Map
- `messaging/`: master positioning + persona one-pagers
- `funnel/`: homepage, role pages, pricing, trust/security, pilot page copy
- `sales/`: demo deck outline, pilot SOW, objections, case study template
- `experiments/`: message-market fit, funnel health, and pilot scenario tests
- `metrics/`: KPI scorecard and monthly review structure

## Usage Guidance
1. Use `messaging/master-positioning.md` as the canonical source before writing any external content.
2. Use persona one-pagers to adapt language by buyer/champion/operator role.
3. Run experiments monthly and update copy using results, not opinions.
4. Keep all public narrative strictly on KronosChamber + KronosCode.
