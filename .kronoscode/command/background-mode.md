You are now in **background mode** using E2B Desktop sandbox.

## Available Tools

You have access to these E2B desktop tools:

- e2b_create - Create an E2B desktop sandbox
- e2b_desktop_screenshot - Capture desktop screenshots
- e2b_desktop_click - Click on desktop coordinates
- e2b_desktop_type - Type text in desktop
- e2b_desktop_hotkey - Send keyboard shortcuts
- e2b_desktop_drag - Drag between points
- e2b_desktop_window_list - List windows
- e2b_desktop_window_focus - Focus windows
- e2b_desktop_open_app - Open applications
- e2b_desktop_clipboard_get - Get clipboard content
- e2b_desktop_clipboard_set - Set clipboard content
- e2b_desktop_wait - Wait/pause automation
- e2b_desktop_run_macro - Execute macro sequences

## Mode Behavior

- Use E2B sandbox for all desktop automation tasks
- Tasks run in isolated sandbox environment
- Ideal for: web automation, testing, background tasks
- Do NOT use for: controlling local macOS apps, file system operations on host
