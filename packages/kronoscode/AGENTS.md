# KronosCode Core

AI coding agent core engine. TypeScript with Bun runtime.

## Overview

The main KronosCode engine - handles AI interactions, tool execution, and agent orchestration.

## Database

- **Schema**: Drizzle schema lives in `src/**/*.sql.ts`
- **Naming**: snake*case for tables/columns; join columns are `<entity>_id`; indexes are `<table>*<column>\_idx`
- **Migrations**: generated by Drizzle Kit using `drizzle.config.ts`
- **Command**: `bun run db generate --name <slug>`
- **Output**: creates `migration/<timestamp>_<slug>/migration.sql` and `snapshot.json`
- **Tests**: migration tests should read per-folder layout (no `_journal.json`)

## Scripts

```bash
bun run dev           # Run kronoscode
bun run db generate  # Generate migration
bun run db push      # Push schema to DB
bun run typecheck   # Type checking
```

## Entry Points

- `src/index.ts` - Main entry
- `src/db/` - Database schema and queries

## Key Dependencies

- `ai` - AI SDK
- `hono` - HTTP framework
- `drizzle-orm` - Database ORM
- `zod` - Validation
